# MoneyMaker

An evidence-first open-source bounty radar and income experimentation lab.

This repository tracks paid open-source issues, rejects closed or suspicious listings, and keeps practical, tested submission material together.

## Principles

- Verify that the original GitHub issue is open before doing any work.
- Treat advertised rewards as unconfirmed until the sponsor and payment terms are checked.
- Prefer active maintainers, limited competition, and reproducible acceptance criteria.
- Respect project contribution guidelines and AI-use policies.
- Never submit speculative security reports or low-quality generated pull requests.

Implementation, tests, and verified opportunities are being added in this repository.
